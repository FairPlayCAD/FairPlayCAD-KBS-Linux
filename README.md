EN:

FairPlayCAD-KBS is a specialized application for generating clamping bricks for 3D printing. The program was designed so that even people with no prior design
experience using CAD can create basic clamping bricks in a short amount of time. To ensure that the snap-together parts fit together properly and function
correctly, key areas of the parts can be adjusted independently of one another for 3D printing.

Bricks created with FairPlayCAD-KBS are compatible with building bricks in the 8x8x9.6 mm grid from various manufacturers. FairPlayCAD-KBS allows you to freely
design snap-together bricks in certain areas. This makes it possible to create snap-together bricks that are not available in these shapes, especially when you
need special adapters for specific building techniques.

Bricks created with FairPlayCAD-KBS can be exported in STL file format to prepare the design for 3D printing. Ultimaker Cura v4.9.0 was tested as a slicer and
is therefore recommended. However, other slicers should also be able to process the exported parts. Further editing of the STL file using 3D CAD or 3D modeling
software is also possible.


DE:

FairPlayCAD-KBS ist eine Spezialanwendung zum Generieren von Klemmbausteinen für den 3D-Druck. Das Programm wurde so konzipiert, dass auch Personen, die noch
keine Konstruktionserfahrungen mit einem CAD haben, in kurzer Zeit, Basisklemmbausteine erstellen können. Damit die Klemmbausteine auch richtig klemmen und
funktionieren, können wesentliche Klemmbausteinbereiche unabhängig voneinander für den 3D-Druck angepasst werden.

Klemmbausteine die mit FairPlayCAD-KBS erstellt würden, sind kompatibel mit Klemmbausteinen im Raster 8x8x9,6mm von verschiedenen Herstellern. FairPlayCAD-KBS
bietet die Möglichkeit, Klemmbausteine in einigen Bereichen frei zu gestalten. Dadurch lassen sich Klemmbausteine erstellen, die in diesen Formen nicht
erhältlich sind. Besonders, wenn man spezielle Adapter für bestimmte Bautechniken benötigt.

Klemmbausteine die mit FairPlayCAD-KBS erstellt würden, können im STL-Dateiformat exportiert werden um die Konstruktion, für den 3D-Druck bereit zu stellen.
Als Slicer wurde Ultimaker Cura v4.9.0 getestet und wird somit empfohlen. Jedoch dürften auch andere Slicer in der Lage sein, die exportierten Teile zu
verarbeiten. Auch eine weitere Bearbeitung, der STL-Datei, mit einem 3D-CAD oder 3D-Modellierungssoftware ist möglich.
